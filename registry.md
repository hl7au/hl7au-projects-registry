# HL7 AU Project Registry

Source of truth for the registry view. Edit this file, then run `python build.py` to
regenerate `index.html`.

Allowed statuses: `Proposed`, `Submitted`, `Approved`, `Active`, `Inactive`, `Withdrawn`,
and `Published` for PSS rows only.

Format: one `##` heading per project (`## <Project ID> <Title>`), followed by its
`Status:`, `Submitted:` and `PP:` fields, then an optional table of its project scope
statements. Leave `PP:` empty for a project with no project proposal on file. Projects
appear in the view in the order they appear here.
